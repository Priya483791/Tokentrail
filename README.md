# TokenTrail – Think in Tokens. Understand AI.

An interactive learning platform designed to help beginners understand Tokenization and Context Window Management in Large Language Models.

## 🚀 Live Project

**Explore the interactive website:**  
https://priya483791.github.io/Tokentrail/

## 💻 GitHub Repository

https://github.com/Priya483791/Tokentrail

## 📚 Project Overview

TokenTrail contains seven interactive learning modules covering:

1. How LLMs Read Text
2. Understanding Tokenization
3. How BPE Works
4. Understanding Context Windows
5. Token Budget Management
6. Context Management Strategies
7. Practical Challenge

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Vite
- gpt-tokenizer (o200k_base)

## ▶️ Run Locally

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open the terminal and run:

```bash
npm install
npm run dev
```

4. Open the local URL displayed in the terminal.
